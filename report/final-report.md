# 最终报告 — 个人网站规范化 AI 开发

## 项目定位
基于静态 HTML/CSS 的个人简历网站，部署在 GitHub Pages。项目目的是通过 OPC-AI 培训营要求的 Vibe → Spec → Harness 规范化流程，完成一个内容真实、手机与电脑均可访问的个人网站，并掌握 AI 辅助开发的方法论。

## 模板选择
本项目从零构建静态网站，不使用现成 Jekyll 模板。选择理由：
- 无需 Ruby/Jekyll 环境即可本地预览
- 完全控制每一行代码，便于按需修改
- 文件结构简单，适合非计算机专业同学理解和维护
- 后续可无缝迁移到教师提供的统一模板

## 主要修改
本项目为从零创建，因此无"模板修改"操作，而是直接构建了包含以下内容的完整页面：
- 导航栏（固定顶部，移动端折叠）
- Hero 区块（姓名、定位、行动按钮）
- About 区块（个人简介 + 信息卡片）
- Skills 区块（6 宫格技能卡片）
- Projects 区块（3 个项目卡片）
- Contact 区块（GitHub + Email 链接）
- Footer 版权信息

## AI 参与
- Codex (GPT-5 Agent) 负责读取简历 PDF 提取信息
- AI 生成网站 HTML/CSS/JS 代码框架
- AI 生成 PRD、Design、Checklist 文档
- AI 协作完成 Git 初始化和提交管理
- 所有内容均基于用户提供的真实简历，AI 未虚构任何信息

## 个人判断
- 隐私处理：手机号码未出现在任何公开文件中，仅使用邮箱和 GitHub 作为联系方式
- 内容真实：所有个人信息、技能、项目经历均来自用户简历
- 项目更新：将"小米公司行业分析研究"替换为两个2026年7月的新项目——"北交所股票投资价值研究"（基于265家上市公司截面数据的因子与聚类分析）和"银行个人客户增长与价值运营"（基于逻辑回归/随机森林的客户响应预测评分卡）
- 项目描述基于PPTX报告内容生成，确保信息准确
- 技术选型：选择了最简单的静态 HTML 方案以确保可靠性和可维护性
