# PRD — 个人网站产品需求文档

## 项目概述
基于静态 HTML/CSS 模板的个人简历网站，部署于 GitHub Pages，作为 OPC-AI 培训营模块三的规范化 AI 开发作业。

## 目标访问者
- **教师与助教**：评估作业完成质量与规范化流程
- **同学与同行**：了解个人背景与能力
- **潜在雇主或合作伙伴**：获取联系方式和项目信息

访问者最先寻找的信息：我的身份、专业背景、核心技能和项目经历。

## 希望访问者记住
- 我是深圳大学金融科技专业的本科生
- 具备金融知识与编程技能的双重能力
- 有真实的社会实践和行业分析项目经验

## 本期必须包含的内容
1. **Hero 区块**：姓名、一句话定位、明确行动入口
2. **About 区块**：真实个人简介、学习方向、校园经历
3. **Skills 区块**：真实能力/工具/兴趣方向
4. **Projects 区块**：至少 1 个真实项目卡片
5. **Contact 区块**：至少提供 GitHub 主页链接
6. **响应式设计**：桌面端与手机端均可正常浏览

## 本期明确不做什么
- 不包含登录系统、数据库、后台管理
- 不包含访客追踪和分析
- 不包含复杂 JavaScript 框架
- 不公开手机号码、家庭住址、身份证件
- 不发布课程邀请码和作业代码
- 不实现多页面路由，仅单页展示

## 怎样判断网站完成
- 所有 5 个区块内容真实且无模板占位
- GitHub Pages 链接可在无痕窗口打开
- 桌面端和手机端均正常显示
- README、docs/ 三份文档、report 完整
- 至少 4 张截图作为验收证据

## 哪些信息不能公开
- 个人手机号码
- 课程邀请码
- 作业代码
- API Key、Token、.env 等敏感信息

## 技术栈
- HTML5 + CSS3 + Vanilla JavaScript
- Font Awesome 6.5（图标库）
- GitHub Pages（部署）
- Git（版本控制）
