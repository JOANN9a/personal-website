# 尚奕颖 · 个人网站

深圳大学金融科技学院金融科技专业本科生的个人简历网站，展示个人信息、技能、项目经历及联系方式。

## 模板来源

本项目为从零构建的静态 HTML/CSS 个人网站，不使用第三方 Jekyll 主题模板。参考设计风格为简约学术风。

## 主要修改

- 本项目为从零创建，无模板修改过程
- 内容完全基于个人真实信息（尚奕颖 · 深圳大学金融科技专业）
- 包含 Hero、About、Skills、Projects、Contact 五个完整区块

## 隐私说明
